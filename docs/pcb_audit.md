# PCB electrical and footprint audit — 2026-09-26

Run `python3 manage.py audit` after schematic or PCB changes. It runs the project checks and ERC, then KiCad DRC with zone refill, all track errors, all severities, and schematic parity. It compares every PCB pad net with the exported schematic netlist. The report is `.recovery/audit/drc_all.txt`. This comparison checks connectivity, not whether a chosen physical module has the same header order.

## Findings that still require a design decision

1. **J6 function conflict:** J6 is named `pico hdmi` and carries MOSI, MISO, PICO_CS, GND, and **SWCLK** on pin 5. It has no SPI SCK or 3V3. PA14/SWCLK has no SPI1_SCK alternate function, so J6 cannot act as a standard SPI peripheral header as wired. Debug clock activity will also reach J6. Decide J6's intended device and pinout before using it. The MCU's main WIZ850io and SD SPI pins have no such conflict.
2. **WIZ850io physical overlap is hidden from normal DRC:** U3 has no F.CrtYd, and `missing_courtyard` is ignored in project rules. A disposable DRC probe using the vendor's 23×25 mm body and jack projection as a courtyard found overlap with H3, R3, and R4, including H3 and four resistor PTH pads inside that footprint. The module may clear the resistors if mounted on tall sockets, but H3 hardware and underside clearance depend on actual assembly height. Verify socket and screw hardware, then add an assembly-appropriate courtyard and relocate conflicts before fabrication. The RJ45 projection also reaches about 0.94 mm beyond the top board edge; check enclosure clearance.
3. **Ground:** Full DRC reports two open GND connections: J1 shell pad SH and an isolated F.Cu GND zone island. Both were left for manual resolution. All other signals pass copper clearance checks.
4. **Power and USB behavior:** WIZ850io is about 141 mA in normal operation and U2 EN follows VBUS, so the Ethernet module powers immediately. Confirm the intended USB bus power behavior before claiming compliance. The USB pair has about 0.09 mm length difference, but board stackup and differential impedance have not been specified or measured.
5. **Assembly data:** R1–R6 and C1–C3 lack manufacturer part numbers, so nominal 0805 package compatibility and the unusual SMD/PTH combination cannot be fully certified. U3's third-party footprint should be matched against the received module/socket revision. The input and output regulator capacitors are present but roughly 10–12 mm from U2; review placement against the regulator's layout guidance.

Baseline full DRC: 2 GND opens, 18 silk text-height warnings, 0 footprint errors, 0 schematic parity errors, and no signal routing clearance violations. The ERC has 0 errors and one known J1 library-symbol mismatch warning caused by the user-edited embedded symbol. These counts do not prove mechanical fit, signal integrity, or USB power compliance.
